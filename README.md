# 🐢 Python Turtle Art

A collection of creative **Python Turtle Graphics** projects created while learning and experimenting with Python.

This repository contains different drawings, patterns, logos, and digital artwork generated entirely through Python code using the built-in `turtle` module.

## 🎨 Projects

| # | Project                 | Description                                                               |
| - | ----------------------- | ------------------------------------------------------------------------- |
| 1 | 🟥 **100 Square Art**   | Generates 100 randomly positioned squares with different colors and sizes |
| 2 | 🎨 **Combined Art**     | A collection of geometric Turtle patterns and colorful designs            |
| 3 | 🔴🔵🟢 **Audi Logo**    | Draws a colorful four-ring Audi-inspired logo                             |
| 4 | 🌀 **Amazing Art**      | Creates a geometric spiral/star-like pattern using loops                  |
| 5 | 🌈 **Colorful Circles** | Generates multiple colorful circular patterns                             |
| 6 | 🔵🔴🟡⚫ **Nice Circle** | Creates a four-color circular artwork with a custom signature             |
| 7 | 🐱 **Doraemon**         | Draws Doraemon using Python Turtle and custom functions                   |

## 🛠️ Technologies

* 🐍 Python 3
* 🐢 Python Turtle Graphics
* Random number generation

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-turtle-art.git
```

Enter the project directory:

```bash
cd python-turtle-art
```

Run any project:

```bash
python doraemon.py
```

For example:

```bash
python 100_squares.py
```

```bash
python audi_logo.py
```

```bash
python amazing_art.py
```
